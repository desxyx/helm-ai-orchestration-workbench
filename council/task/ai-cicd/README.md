# WatchOver / AI_CICD: the available process archive

This is an English, translated and redacted archive of the available work behind [WatchOver AI DevOps](https://github.com/helmls-studio/watchover-ai-devops). It follows the requirements, Council debates, implementation and reviews, deployment experiments, manual coordination, Windows handoff, product rework and public-edition delivery. Summaries here are navigation; the linked records retain disagreements, failed checks, missing evidence and the Human Operator's own voice.

W1 is the exploratory baseline. W2 contains two executed arms, Bare and WatchOver Basic: **both formal results are INVALID**, with assisted descriptive observations rather than an eligible unassisted causal comparison. W2C was NOT_EXECUTED. W3 is one Windows Basic run with a changed workload, model and client; it does not establish a general causal benefit. Keep raw FAIL, effective UNVERIFIED and reported working behavior distinct.

The public product is version **0.1.2**, commit `5c662eac0449bd30eddd01c606d268f0aa510631`. This archive does not alter that product. [Agent Run Recorder](https://github.com/helmls-studio/agent-run-recorder) and the historical experiment-control/checkpoint tools are separate from WatchOver's local guidance and records.

## What is available

The primary capture cutoff is 2026-10-08T00:40:06.630418+11:00; an explicit retained-export supplement was frozen at 2026-10-08T00:59:27.231687+11:00. The private inventory contains 4,962 ordinary-file entries across the three primary source families and bounded retained exports. Public hashes bind these public derivatives only.

Three captured Council sessions contain **32 rounds and 96 reply entries**. A reply entry can be a timeout, refusal, error or incomplete capture; 96 does not mean 96 complete answers. Later Council messages are file-based records. W1 retained native item-array exports recover part of its dialogue; the full original native session and its completeness remain unestablished. Overlapping W2 transcript prefixes and W1 checkpoint exports use references rather than new conversations. Images are represented by 25 actually inspected English textual descriptions; original pixels are omitted.
