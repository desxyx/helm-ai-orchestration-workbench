### IV. Architecture discussion

Four important tradeoffs from frontline answers/External Team change request 001:

#### 1. UI is a state-machine projector, not an interactive console

Human need is current truth lost in long terminal conversations. Reviewer warns manually maintained MERGE_BACKLOG.html inevitably drifts. Use one AI-maintained STATE.json; frontend JS periodically fetches it. Page says “Waiting for approval: reply ‘authorize Stage 3’ in terminal/chat, confirming these effects…”, without click-to-execute backend. Clear status, no heavy backend.

#### 2. Secret registry

You fear redaction makes passwords lost and favor plaintext if necessary; actual plaintext in repositories creates serious consequences/blocks. **Store names/readiness, never values.**

* DB_ROOT_PASSWORD: VERIFIED-PRESENT in local uncommitted .env;
* KEYCLOAK_ADMIN_PASSWORD: VERIFIED-PRESENT;
* MAPPER_APP_SECRET: BLOCKED, administrator must provide.

Tells successors what exists/misses without encryption-library complexity, avoiding safety/compliance issues.

#### 3. Replace huge MCP collections with staged prompt routing

Frontline work used gcloud/gh/Compose/curl adequately; no stall came from missing third-party MCP. Hundreds/thousands of links add maintenance/context noise without résumé depth. Small Markdown rules such as 01_preflight_rule.md, 02_cost_estimation_rule.md and 03_deploy_gate_rule.md encode discipline: read-only first, resources/assumptions in planning, command templates at execution. This best demonstrates ideas and delivery.

#### 4. Gates at stage boundaries, not every command

Even ls/curl/Compose ps waiting for approval would kill collaboration. Gates at three boundaries only:

1. Preflight → plan selection: confirm target/budget;
2. Before irreversible/billable action: VM, disk formatting, deletion, DNS;
3. Before public traffic/live release: final health check/handoff snapshot.

**Conclusion:** very worthwhile if lightweight connections, snapshots and shared staged work remain core. Useful handoff tool and excellent demonstration of orchestration/governance/complex delivery. Support formal progress within narrowed scope.
