# Executor Charter — Public v1.1 — C4 — External Deliverable / Release

Trigger: an artifact is about to leave the workbench boundary to an external audience. Confirm an explicit, named, authorized release owner. If the task requires review, confirm the review owner separately. Review authority is not release authority: PASS does not send, publish, merge or release anything. Without a required owner the artifact stays local; reporting the gap does not authorize release. High-impact approval follows Executor §E2.3, while any Council involvement follows the active constitution/task boundary.
